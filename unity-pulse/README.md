# Unity Pulse 🏙️

Образовательная веб-игра об Ассамблее народа Казахстана.

Разработана студентами APEC Petrotechnic:
- Аманбай Айкен Ақылбекқызы
- Жумакулова Асылай Маратовна
- Тулегенова Аружан Руфатовна

## Установка и запуск

```bash
npm install
npm run dev
```

Открой браузер: http://localhost:5173

## Сборка для продакшн

```bash
npm run build
```

Готовые файлы будут в папке `dist/` — их можно загрузить на любой хостинг.

## Структура проекта

```
src/
├── App.jsx                    # Корневой компонент, управляет экранами
├── App.css                    # Глобальные стили
├── main.jsx                   # Точка входа React
├── data/
│   └── levels.js              # Все уровни, вопросы и ответы
└── components/
    ├── IntroScreen.jsx/css    # Экран приветствия
    ├── MapScreen.jsx/css      # Карта города с уровнями
    ├── LevelScreen.jsx/css    # Экран прохождения уровня
    └── FinalScreen.jsx/css    # Финальный экран
```

## Как добавить вопросы

Открой `src/data/levels.js` и добавь объект в массив `questions` нужного уровня:

```js
{
  text: 'Текст вопроса?',
  hint: 'Подсказка (необязательно)',
  options: ['Вариант А', 'Вариант Б', 'Вариант В', 'Вариант Г'],
  correct: 1,  // индекс правильного ответа (0-3)
  feedback: 'Объяснение правильного ответа.'
}
```
